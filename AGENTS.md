# Anki Project Entry Point

This repository is the durable source of truth for the user's Anki deck-building system.
When the user says “do what we always did in Anki,” “use my usual Anki workflow,” or similar,
read `anki-system/SKILL.md` first and route the task through the relevant skills listed there.

Durable preferences agreed during Anki work must be incorporated into the appropriate skill,
not left only in chat history. Keep changes synchronized to the public GitHub repository and
the OneDrive working copy after validation. Never put the live Anki collection database in Git.
